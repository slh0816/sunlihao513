第一部分：看代码找错（20分）

共3处bug，逐一分析如下：

Bug 1：图片放大跑出卡片，盖住旁边卡片

错误位置：.box li 缺少 overflow: hidden 和 position: relative

原因：图片 hover 时 scale(1.2) 放大后超出 li 容器边界，没有裁切；同时文字条 .txt 使用 position:absolute 但 li 没有设置 position:relative 作为定位父级。

修改后代码：

.box li{
  width: 300px;
  overflow: hidden;          /* 裁切放大溢出的图片 */
  position: relative;        /* 为 .txt 的 absolute 定位提供父级 */
}

Bug 2：文字展开只有移入有动画，鼠标移出无过渡效果

错误位置：transition: all .6s; 写在了 .box li:hover img 里

原因：transition 写在 hover 选择器上，只有鼠标移入时才生效；鼠标移出时 hover 状态消失，transition 也随之消失，因此没有过渡动画。

修改后代码：

.box img{
  width: 100%;
  transition: all .6s;       /* transition 写在默认选择器上，移入移出都有动画 */
}
.box li:hover img{
  transform: scale(1.2);
  /* transition 不再写在这里 */
}

Bug 3：卡片布局排版错乱

错误位置：.box 的 display: flex 缺少 flex-wrap: wrap

原因：flex 默认不换行（flex-wrap: nowrap），所有 li 会被挤在一行，导致布局错乱。

修改后代码：

.box{
  display: flex;
  flex-wrap: wrap;           /* 允许卡片换行排列 */
}

第三部分：手写原理简答（25分）

1. 子绝父相盒子位置关系图

父元素设置 position: relative 后，子元素设置 position: absolute，子元素的定位参考点是父元素的内容区域左上角（而非整个页面）。

─────────────────────────────┐  ← 父元素 position:relative
│  ┌──────────┐               │
│  │ 子元素    │               │  ← 子元素 position:absolute
│  │absolute  │               │     相对于父元素定位
│  ──────────┘               │
│                             │
└─────────────────────────────┘

2. overflow:hidden 本节课两个作用

  • 作用1：裁切溢出内容 —— 当子元素尺寸超出父元素时（如图片 scale 放大），隐藏超出部分，防止溢出遮挡相邻元素。
  • 作用2：创建 BFC（块级格式化上下文） —— 使父元素能够包含浮动的子元素，同时为 position:absolute 的子元素提供定位参考（配合 position:relative 使用）。

3. transform:scale(1.2) 会不会把盒子实际占位变大？

不会。transform: scale() 只是视觉上的缩放变换，属于 GPU 加速的渲染层变换，不会改变元素在文档流中的实际尺寸和占位。因此不会挤压或影响旁边卡片的布局位置。这也是为什么需要配合 overflow:hidden 来裁切视觉上溢出的部分。

4. transition 写在 hover 上 vs 写在普通选择器上的区别

写在 hover 选择器上：鼠标移入时有过渡动画，但鼠标移出时 hover 状态立即消失，transition 属性也随之失效，因此移出时没有过渡动画，元素瞬间恢复原状。

写在普通（默认）选择器上：无论鼠标移入还是移出，transition 属性始终存在，因此移入和移出都有平滑的过渡动画。

5. 代码bug记录

现象：卡片中图片 hover 放大后，图片超出了卡片边界，覆盖到了旁边相邻的卡片内容。

排查过程：首先检查了图片的 transform: scale(1.2) 是否正确，确认放大效果本身没问题。然后检查父元素 li 的样式，发现没有设置 overflow 属性。再检查 .txt 文字条的定位，发现 li 也没有设置 position:relative。

修复方法：在 .box li 中添加 overflow:hidden 裁切溢出图片，同时添加 position:relative 为文字条的绝对定位提供父级参考。

第四部分：扩展挑战 —— 回到顶部CSS代码（15分加分）

纯CSS实现左下角回到顶部按钮，利用 :target 伪类和锚点跳转：

/* 回到顶部按钮样式 */
.back-to-top {
  position: fixed;          /* 固定在视口左下角 */
  left: 20px;
  bottom: 20px;
  opacity: 0.5;             /* 初始半透明 */
  z-index: 999;             /* 保证浮于页面内容之上 */
  transition: all 0.3s;     /* 平滑过渡动画 */
  text-decoration: none;
  color: #fff;
  background: #2774bd;
  width: 50px;
  height: 50px;
  border-radius: 50%;
  text-align: center;
  line-height: 50px;
  font-size: 20px;
}
.back-to-top:hover {
  opacity: 1;               /* hover完全不透明 */
  transform: scale(1.15);   /* 同时轻微放大 */
}

/* 页面顶部锚点 */
#top {
  scroll-behavior: smooth;  /* 平滑滚动（写在html上更佳） */
}
html {
  scroll-behavior: smooth;
}

HTML用法：在页面顶部添加 <div id="top"></div>，在页面任意位置放置 <a href="#top" class="back-to-top">↑</a>，点击即可回到顶部。
