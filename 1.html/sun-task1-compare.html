任务一

提示词工程师 · 一句需求，两版配置

作业要的配置有四条硬指标：首尾相接不中断、3.2 秒自己走一步、被手动碰过也不能停、圆点按下去要真跳转，初始效果还得是 cube。
下面两个轮播都是活的：左边喂的是第一版提示词，右边是改过一版。两边的 HTML 一字不差，只差一个配置键。亲手点一点圆点，读数会把结论写给你看。

01

同一段需求，两版配置

两个轮播的 HTML 逐字相同，配置只差一个 clickable。点圆点试试，下面那行读数会实时告诉你哪边真的动了。

02

每条要求，落在哪个参数上

答辩最怕被追问“你这句话对应哪个键”。下面这张对照表，是我交卷前反复默写过的部分。

需求原话落到的参数为什么只能是它
整圈循环不卡头 loop: true 末张再往后翻要接回第一张；不写这条，翻到头就死在最后一张
3.2 秒自己走一步 autoplay: { delay: 3200 } 停顿时长挂在 delay 上，单位毫秒，3.2 秒就填 3200
被碰过还要接着走 autoplay.disableOnInteraction: false 这项缺省是 true，手指一碰定时器就被掐掉；整张表里最容易漏的一行
圆点按下要跳页 pagination: { el, clickable: true } el 管画在哪，clickable 管能不能按，两个键各干一件事
一开屏就是立方体 effect: 'cube' effect 只在 new 的时候读一次，事后再改参数不生效，必须销毁重建
03

两版提示词，改在了哪

第一版做的是“照着字面翻译”，第二版做的是“把动作补全”。真正起作用的，是那句“点了之后要发生什么”。

第 1 版 · 原文
帮我写一个 Swiper 的初始化配置。要求：循环播放、3.2 秒自动换一张、手动操作后不要停、要有圆点分页器、效果用 cube。
  • 原话给的是名词，没说按下之后要干嘛
  • AI 走最省力路线：能渲染出来就当交差
  • 四条里有一条属于“看着像对、上手就废”
第 2 版 · 原文
上一版还差一处：那些圆点不光是摆着看，必须能直接点，点到哪个就跳到哪张。其余配置原样别动。
  • 名词改动词：按下 → 跳转
  • 顺手堵死歧义：不是装饰，不是只显示
  • 圈定改动范围：其余原样，防止它顺手把好的改坏
答辩要点：如果老师问“第一版为什么漏”，别急着甩锅给模型——需求里只有名词、没有动作。pagination.el 决定圆点画在哪，pagination.clickable 决定圆点按不按得动，中文的“分页器”一个词把两件事糊在一起，AI 只能先挑一件做。问题不在它不聪明，在我翻译时少写了半句。
04

验收不是把配置念一遍，而是把每条需求在页面上亲手做一次，再读实例状态去对答案。
