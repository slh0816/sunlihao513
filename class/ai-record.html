任务一 · 提示词工程师

用提示词生成 #wySw4 的完整配置

1. 原始需求 （一句话）

让 AI 输出一段 new Swiper('#wySw4', {...})，同时满足无缝循环、3.2 秒自动翻页、圆点可点击、cube 立方体四种效果。

第 1 轮 · 提示词原文
帮我生成 new Swiper('#wySw4', {}) 里面的配置对象，要求：无缝循环轮播，3.2秒自动翻页，带可以点击的圆点分页器，切换效果是 cube 立方体效果。只输出大括号内配置，不要多余代码。
AI 给出loop:true、effect:'cube'、autoplay:{delay:3200,disableOnInteraction:false}、pagination:{el:'#wyPag4',clickable:true}、cubeEffect:{...}
关键结论切换 effect 属初始化参数；cube 需配 cubeEffect 才有立体阴影；pagination 必须同时写 el 和 clickable
2. 我实测发现的问题 （对应参数）
  • 第一版提示词漏掉了"交互后自动播放不能停"这条需求，只说了"3.2 秒自动翻页"，对应的参数是 autoplay.disableOnInteraction（必须显式写 false，默认是 true）。
  • cube + loop 回绕到第一张时闪白，缺的是 loopAdditionalSlides——这一条 AI 第一次确实没给，是真遗漏。
  • 圆点"点了没反应"：参数本身 pagination.clickable 已写了，实测原因是 #wyPag4 不在 #wySw4 容器内 / 粘贴时丢了行，不是参数错。
第 2 轮 · 提示词原文
你上一版我实测有三个问题，请修正后重新输出完整配置： 1. 缺需求：我要求"手动滑动或点圆点之后，自动播放不能停"，你给的效果是操作一次就不再自动翻了。 请检查 autoplay 里控制"交互后是否继续自动播放"的那个参数名，把它显式写出来。 2. cube 效果下只写 loop:true 循环不顺，回到第一张会闪一下，请说明还需要哪个参数配合。 3. 圆点分页器点了没反应，请把分页器配置写全（el + clickable）。 输出要求： ① 完整可用的配置代码； ② 一张 4 行表格：需求 → 对应参数名 → 这个参数的作用； ③ 列出你自己不确定、需要我实测的点。
关键往返：AI 说明 disableOnInteraction 是"交互后是否停止"的开关；补出 loopAdditionalSlides:1 用于回绕补位；并主动列出"1 还是 2 需要实测""delay 与 speed 的衔接需实测"等不确定项。
3. 修正后的最终配置
最终生效代码
var swiper4 = new Swiper('#wySw4', { loop: true, loopAdditionalSlides: 1, // 回绕时多复制 1 张，消除闪白 effect: 'cube', speed: 800, autoplay: { delay: 3200, disableOnInteraction: false }, pagination: { el: '#wyPag4', clickable: true }, cubeEffect: { shadow: true, slideShadows: true, shadowOffset: 20, shadowScale: 0.94 } });
4. 验证
操作：停在最后一张，点右箭头一次；再点第 3 个圆点；再拖动后松手等待。
现象：回绕无空白帧；点到第 3 张立即切换且第 3 个圆点高亮；松手后 3.2 秒继续自动翻。
结论一句话：四项需求全部生效，loopAdditionalSlides 与 disableOnInteraction 是决定成败的两个参数。
任务二 · creative 仿写（课堂未讲）

给演示四新增第 7 个按钮「creative 电影墙」

1. 原始需求

用官方 creativeEffect 做「电影选片墙」：上一张缩小左移带角度退到左后，下一张放大右移进场。

第 1 轮 · 提示词原文
使用 Swiper creativeEffect，写一个电影选片墙效果：退场的上一张 slide 缩小、向左偏移、带一点旋转角度；入场的下一张 slide 放大、向右偏移；当前在中间的卡片正常大小居中。给我 creativeEffect 的配置，加上阴影，限制动画范围。
prev / next按位置生效：prev = active 左边那张，next = 右边那张，翻页瞬间两者互换身份，active 恒为单位变换
单位translate 数字为 px、百分比相对 slide 自身宽/高；rotate 为纯数字角度；scale 为倍数；opacity 为 0~1
限制范围limitProgress 控制左右各几张参与变换
2. 我实测发现的问题
  • rotate 写成 '9deg' 字符串无效，必须写纯数字 -9，否则整条 rotate 被忽略。
  • 网上有资料给出 setTransform: true，实测毫无变化——官方 CreativeEffectOptions 里没有这个键，属于 AI 编造参数。
  • 侧方两张"被盖住/露不出来"，实质是 translate 的 X 太小（-20%）叠加 Z 负值导致层级下沉。
第 2 轮 · 提示词原文
三个追问，简短回答，不要重复上面的代码： 1. prev 的 transform 和 next 的 transform 各自控制的是"离场那张"还是"进场那张"？ 2. transform 里的百分号是相对视口、相对容器、还是相对 slide 自身宽高计算的？ 举一个具体数字说明它实际移动了多少像素。 3. 我把 rotate 从 '30deg' 改成 '20deg'，视觉上哪个动作变弱？ 把 translateX 从 '-50%' 改成 '-20%'，上一张会不会被当前这张盖住，为什么？
关键往返：确认百分比相对 slide 自身（760px 宽 → -38% ≈ −289px）；确认 '30deg' 是非法值；确认 Z 为负 + DOM 顺序靠前 → 必然被 active 压住。
3. 修正后的最终配置
按钮 HTML（沿用原有结构）
<button data-fx="creative">creative 电影墙</button>
切换逻辑：销毁重建（effect 属初始化参数）
if (swiper4) { swiper4.destroy(true, true); } swiper4 = new Swiper('#wySw4', { loop: true, effect: btn.dataset.fx, speed: 800, mousewheel: { forceToAxis: true }, autoplay: { delay: 3200, disableOnInteraction: false }, pagination: { el: '#wyPag4', clickable: true }, creativeEffect: { limitProgress: 2, shadowPerProgress: true, prev: { translate: ['-38%', 0, -220], rotate: [0, 0, -9], scale: 0.82, opacity: 0.6, shadow: true }, next: { translate: ['38%', 0, -90], rotate: [0, 0, 6], scale: 1.06, opacity: 0.65, shadow: true } } });
4. 验证
操作：点「creative 电影墙」，再点 next 箭头连续翻两张；随后切回 cube、fade。
现象：上一张缩小左偏并带 −9° 倾角退场，下一张从右侧 38% 处放大进场并半透明，中间卡片正常；切其它效果照常工作。
结论一句话：creativeEffect 是"位置状态"而非"动画脚本"，两套静态状态由 Swiper 按进度插值。
任务三 · 综合创作（超纲加分）

新增展品「爱达·魔都号」+ 课堂未讲的 mousewheel

1. 原始需求

补一件 AI 生成图片的新展品，并给 Swiper 加一项课堂未讲的能力，我选了鼠标滚轮翻页。

第 1 轮 · 提示词原文
横版 16:9，写实摄影，首艘国产大型邮轮爱达·魔都号，海面平稳航行，柔和白天自然光，全景构图，高清，适合网页轮播展示，干净海面背景，无多余水印文字
给我的 swiper 添加鼠标滚轮切换幻灯片的功能。
图片AI 生成 swiper-imgs/aida_1.jpg（2560×1440），后续再生成停靠版 images/adora-magic-city.jpg
功能只需在配置里加 mousewheel: true；CDN 的 swiper-bundle 已内置 Mousewheel 模块，无需额外注册
2. 我实测发现的问题
  • 滚轮带着页面一起滚：裸写 mousewheel: true 缺 forceToAxis，横向轮播上竖向滚轮不会被映射到翻页轴。
  • 滚一下跳好几张：缺 sensitivity / thresholdDelta / thresholdTime 三个节流参数。
  • 方向若反向，对应的是 invert，必须保持 false。
第 2 轮 · 提示词原文
优化 mousewheel，让滚轮只控制轮播切换，不带动页面滚动，加上 mousewheel 配置 forceToAxis:true
关键往返：确认 forceToAxis:true 才能把竖向滚轮掰到横轴；loop:true 时 releaseOnEdges 不起作用；thresholdDelta/thresholdTime 负责"一次只翻一张"。
3. 修正后的最终配置
滚轮配置（并入原有配置对象）
mousewheel: { enabled: true, forceToAxis: true, // 竖向滚轮也翻页，否则只会滚页面 sensitivity: 1, // 一格滚轮 = 一张 thresholdDelta: 40, // 累计 40px 才触发，过滤触控板碎滚 thresholdTime: 400, // 两次翻页最短间隔 invert: false, // 向下滚 = 下一张 releaseOnEdges: false }
新展品 slide（与其它 6 件同结构）
<div class="swiper-slide"> <img src="swiper-imgs/aida_1.jpg" alt="爱达·魔都号"> <div class="wy-cap"><h3>爱达·魔都号</h3><p>首艘国产大型邮轮 · 2024 年 1 月首航</p></div> </div>
4. 验证
操作：鼠标悬停在轮播上向下滚一格；移出轮播后再滚。
现象：悬停时每次只翻一张且方向与滚动一致；移出后页面正常上下滚动；连续快滚不再一次跳多张。
结论一句话：forceToAxis 决定"翻不翻"，thresholdDelta + thresholdTime 决定"一次翻几张"。
