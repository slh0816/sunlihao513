1. 标题与段落

HTML 使用标题组织内容层级，使用段落承载完整的信息，让页面结构清晰、易于阅读。

通过 h1 到 h6 设置标题层级，使用 p、strong、em 等标签表达文字关系。

本页面将练习网页中常见的基础元素，为后续 CSS 样式和页面设计打好基础。

  • 文本： 标题与段落
  • 媒体： 超链接与图片
  • 数据： 列表与表格
  • 交互： 表单与语义化标签

2. 链接与图片

链接用于连接不同页面和资源，图片则可以补充文字信息，丰富网页的视觉表达。

练习内容包括：文本链接、图片路径、替代文本和基本的图片样式。
